# Órleu Hack 2026: Образование, читать и понимать

Проект для хакатона [Órleu Hack 2026](https://hackathon.kz/hackathon?slug=orleu-hack-2026), кейс 3 «Образование: читать и понимать».

## Задача

Как с помощью ИИ поднять функциональную грамотность (чтение или математика) у учеников 7–9 классов так, чтобы решение работало и в сельской школе со слабым интернетом.

По PISA-2025 базового уровня по чтению достигли только 36% казахстанских 15-летних школьников.

## Решение

Одна система из трёх частей с общей базой заданий, общим ИИ и общим прогрессом ученика:

| Часть | Кто пользуется | Что делает |
|---|---|---|
| Тренажёр (сайт-PWA, работает офлайн) | Ученик | Задания «Расследование», «Найди, где врут», «Помоги семье» |
| Помощник учителя | Учитель | Прогресс класса, слабые навыки по PISA, выдача заданий |
| Telegram-бот | Ученик и родитель | Задание дня, недельный отчёт родителям |

## План работы

Полный план с задачами по частям A, B, C: [PLAN.md](PLAN.md).

## Запуск

Нужен Node.js 20+.

```bash
cd app
npm install
npm run dev      # http://localhost:5173
npm test         # тесты контрактов и аналитики
npm run build    # продакшен-сборка в app/dist
```

Демо без учеников: «Я учитель» → «Открыть демо-класс» (код `DEMO`). Тестовый ученик с QR-кодом: `/demo/qr`.

## Структура

```
app/            PWA (React + Vite + Tailwind)
  src/student/  часть A — приложение ученика (сейчас заглушка)
  src/teacher/  часть C — панель учителя
  src/ui/       часть C — дизайн-система, общие компоненты
api/            часть B — Vercel Functions
content/        часть B — база заданий pack-v1.json (сейчас 9 стартовых), промпты
shared/         контракты для всех: types.ts, elo.ts, qr-protocol.ts (+ тесты)
docs/           часть C — презентация, видео, пилот, сдача, деплой
```
