# Сдача онлайн-этапа (до 27.11, 23:00; наш срок 21:00)

## Описание проекта (≈180 слов, вставить в форму)

**Oqy — ИИ-тренажёр функциональной грамотности для 7–9 классов, который работает без интернета.**

По PISA-2025 только 36% казахстанских 15-летних достигают базового уровня чтения (ОЭСР — 69%). Учителям не хватает готовых контекстных заданий, а онлайн-сервисы плохо работают на слабой сети сельских школ.

Oqy — одна система с тремя входами. **Ученик** решает задания на три навыка PISA (найти, понять, оценить) в приложении, которое работает в режиме самолёта. ИИ не выдаёт ответ, а ведёт лестницей подсказок. **Учитель** получает результаты QR-кодом без интернета, видит карту навыков класса, список тех, кто «уверенно ошибается», и готовые группы на завтра. Любую страницу учебника учитель фотографирует, и ИИ делает из неё задания PISA с подсказками и ключами. **Родитель** получает понятный отчёт в Telegram.

Мы проверили прототип на N школьниках: (цифры пилота).

Стек: React PWA, IndexedDB, QR (deflate + CRC32), Vercel, Supabase, Claude API. ИИ-инструменты разработки: Claude Code.

**Демо для жюри:** откройте ссылку → «Я учитель» → «Открыть демо-класс» (код класса `DEMO`).
