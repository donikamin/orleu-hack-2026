# Часть B: сервер, ИИ, бот

## Локальный запуск

```bash
npm install && npm run dev          # API на 3001; без ключей база в памяти
cd app && npm install && npm run dev  # фронт на 5173, /api проксируется на 3001
npm test && npm run typecheck       # в корне: тесты сервера
```

Ключи для локальной проверки: скопировать `.env.example` в `.env.local` (не коммитится).

## Подключение (по порядку)

1. **Supabase:** новый проект → SQL Editor → выполнить `supabase/schema.sql`. Project Settings → API: URL и service role (secret) key.
2. **ИИ, один из двух:**
   - Claude (по умолчанию): Anthropic Console → ключ в `ANTHROPIC_API_KEY`. Модель по умолчанию `claude-opus-5-5`; дешевле: `AI_MODEL=claude-haiku-5-5` и `AI_MODEL_PHOTO=claude-haiku-5-5`.
   - Gemini: aistudio.google.com → ключ в `GEMINI_API_KEY` и `AI_PROVIDER=gemini`. Модель по умолчанию `gemini-3.5-flash-lite`: большие модели Gemini не укладываются в тайм-ауты приложения.
   Переключиться: сменить `AI_PROVIDER` в Vercel и сделать Redeploy. Код менять не нужно, весь ИИ в `server/ai.ts`.
3. **BotFather:** токен. `TELEGRAM_WEBHOOK_SECRET` и `CRON_SECRET` — любые случайные строки.
4. **Vercel → Settings → Environment Variables:** все имена из `.env.example`, затем Redeploy.
5. После деплоя один раз: `npm run bot:setup -- https://адрес.vercel.app`.

Порядок первых 9 заданий в `pack-v1.json` не менять: по индексу их кодирует QR. Новые добавлять только в конец.

## Поведение при сбоях

| Сбой | Что происходит |
|---|---|
| Нет ключа ИИ, таймаут, отказ | `/hint` отдаёт статическую подсказку, остальное — понятная ошибка, приложение переходит на офлайн-замену |
| Подсказка раскрывает ответ | `server/leak.ts` заменяет её статической |
| Нет Supabase на Vercel | `/pack`, `/hint` работают, классы и синхронизация отвечают 503, остаётся QR |
| Класс создан без интернета | `/sync` отвечает 404, результаты передаются через QR |

Имена не собираем. В ИИ уходят текст задания, ответ ученика, фото страницы и числа для отчёта, без кода класса и номера.
Синхронизация и привязка бота по контракту без пароля: код класса + номер. Чужой чат не может перехватить уже привязанный номер.
