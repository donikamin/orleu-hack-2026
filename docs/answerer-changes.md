# Oqy: ИИ-ответчик и сайт ученика. Что просили и что сделано

> **Для команды и для Claude Code.** Это подробный отчёт о работе капитана (часть C) над сайтом ученика с 26 по 27 ноября 2026: что просили, что сделано, где лежит код, что проверено и что не доделано.
> Общая сводка проекта (кто что делает, запуск, структура, сроки сдачи) лежит в `HANDOFF.md` в корне. Здесь только подробности по сайту ученика и ИИ-ответчику.
> **Для Claude Code:** прочитай сначала `HANDOFF.md`, потом этот файл. Ключи (ElevenLabs, Gemini, Anthropic) в код, коммиты и чат не попадают. Они хранятся только в Vercel → Settings → Environment Variables.

## Коротко

- **Что сделано:** вместо простого чата на экране `/tutor` теперь **ИИ-ответчик**. Это 3D-собеседник: он слышит вопрос голосом, отвечает вслух с движением губ и показывает субтитры. Ещё он читает тексты, фотографирует задачу и говорит по-русски и по-казахски.
- **Без интернета** ответчик отвечает тремя способами:
  - встроенной базой ответов;
  - **локальным ИИ** на самом устройстве (Qwen 2.5);
  - речь тоже распознаётся на устройстве (Whisper).
- **Мотивация в духе Duolingo без копирования.** Есть серия дней, заморозки, XP, уровни, достижения, задача дня, блиц-игра и мини-тест PISA.
- **Для жюри:** экран `/jury` за 3 минуты показывает весь продукт по 5 шагам. На экране `/offline` есть доказательство работы на 2G и без сети.
- **Лёгкость:** приложение кэшируется целиком, это **1,17 МБ**. Тяжёлое (3D, ИИ, распознавание речи) скачивается только по запросу и потом хранится на устройстве.
- Всё на GitHub в `main`: [PR #6](https://github.com/donikamin/orleu-hack-2026/pull/6) и коммит `33b763b`. Исключение — правка качества 3D-аватара: она пока не закоммичена (см. раздел 9).

## 2. ИИ-ответчик (`/tutor`)

**Было:** чат с подсказками и персонаж Айя.
**Стало:** экран из двух частей. Слева 3D-сцена, справа разговор.

### 2.1. 3D-собеседник
- Библиотека **TalkingHead 1.8** (MIT), под ней three.js. Файл `app/src/site/TalkingAvatar.tsx`.
- Две модели в `app/public/avatars/`:
  - `brunette-t.glb`: девушка, Ready Player Me, лицензия CC BY-NC 4.0, 2,8 МБ;
  - `male.glb`: парень, AvatarSDK, только некоммерческое использование. Сжат с 12 МБ до 3,7 МБ (gltf-transform: dedup + meshopt).
- Переключатель «Женский / Мужской» меняет и модель, и голос. После загрузки новой модели она здоровается.
- **Движение губ:** текст переводится в латиницу (LipsyncEn понимает только её). Время слов берётся:
  - для живого голоса — из длины звука;
  - для голоса телефона — из события `onboundary` или из оценки скорости речи.
- Защита от зависания: фраза не может звучать втрое дольше оценки.
- 3D скачивается только при открытии экрана (≈3 МБ один раз), потом лежит в кэше `oqy-3d`.
- **Если 3D не скачан и нет сети, экран не падает.** Ответчик пишет «3D загрузится, когда появится интернет» и отвечает голосом телефона и текстом (коммит `33b763b`).

### 2.2. Что умеет
| Ученик делает | Ответчик |
|---|---|
| Нажимает большой зелёный микрофон и спрашивает | Распознаёт речь, текст появляется в поле, отвечает голосом с субтитрами |
| «Прочитай текст про Арал» | Читает текст вслух, подсвечивает текущее предложение |
| Вставляет длинный текст (больше 280 символов) | Читает его и дальше отвечает по нему («О чём текст?», «Главная мысль?») |
| «Стоп» | Замолкает |
| Нажимает камеру | Фотографирует задачу в приложении. Фото сжимается до ≈50 КБ (уходит и на 2G) и разбирается ИИ на сервере. Без сети ставится в очередь |
| Пишет или говорит по-казахски | Переключает микрофон на казахский и отвечает по-казахски |
| Выбирает РУС / ҚАЗ | Меняет язык распознавания речи |

### 2.3. Откуда берутся ответы (по очереди)
1. **ИИ на сервере** (`/api/tutor`, Gemini или Claude, промпт `content/prompts/tutor.md`). Работает по-сократовски: задачу за ученика не решает, понятия объясняет прямо.
2. **Википедия** для вопросов «кто такой / что такое / расскажи про / … кім?» (`app/src/site/knowledge.ts`):
   - полнотекстовый поиск на kk и ru, страницы-списки значений пропускаются;
   - в ответе 2–3 предложения и источник;
   - ответ кэшируется на телефоне, повторный вопрос отвечается и без сети.
3. **Встроенная база** (`app/src/site/offlineAnswer.ts`):
   - приветствия и «как дела» с несколькими вариантами ответа, по-русски и по-казахски;
   - темы учёбы: проценты, масштаб, графики, факт и мнение;
   - калькулятор выражений (без `eval`);
   - подсказки по тексту, который читали.
4. **Локальный ИИ на устройстве** для любых других вопросов (раздел 4). Если его нет — **Ollama школы** (компьютер учителя в Wi-Fi класса, настраивается в «Мой кабинет»).

Проверено на production-сборке (27.11). Ответы правильные:
- «Привет», «Как дела?», «Кто ты?»;
- «Сәлем! Қалайсың?» → «Бәрі керемет!…»;
- «15% от 24 000» (подсказка без готового ответа), «25 * 4 = 100»;
- «Кто такой Абай?» (из Википедии), «Чем факт отличается от мнения?».

## 3. Микрофон: почему «не слышал» и как починено

**Проблема** воспроизведена в настоящем Edge с тестовым голосом. Встроенное распознавание Edge слышит звук (громкость скачет), но **молча возвращает пустоту** и через 7 секунд выключается без ошибки. Поэтому запасной путь не включался.

**Решение** (`app/src/site/voiceInput.ts`):
- Приложение **всегда само записывает голос**:
  - вокруг кнопки микрофона растёт кольцо громкости — видно, что тебя слышно;
  - запись сама останавливается после 1,2 с тишины;
  - порог шума подстраивается под шумный класс;
  - если 8 секунд никто не говорит, появляется «Не слышу тебя».
- Параллельно работает распознавание браузера: если оно даёт текст, он появляется **в поле ввода прямо по ходу речи**.
- Если браузер ничего не распознал, запись распознаётся:
  1. на сервере `/api/stt` (Gemini), если есть ключ;
  2. **прямо на устройстве**: Whisper base (OpenAI, MIT) через transformers.js, ≈75 МБ один раз, дальше без интернета. Файлы `stt.worker.ts` (отдельный поток, интерфейс не подвисает).
- После первого сбоя браузера приложение запоминает это на сессию и сразу идёт своим путём. Если модель уже скачана, она поднимается заранее при открытии экрана.
- На Android второй поток с микрофона мешает распознаванию, поэтому своя запись там включается только после сбоя браузера.
- Отсеиваются «галлюцинации» Whisper в тишине («Продолжение следует…»).

**Проверено:** фразу «Как найти 15% от 24 000?» Edge не распознал, распознал Whisper на устройстве, и ответчик ответил подсказкой.
**Минус:** без серверного ключа распознавание на ноутбуке занимает около 15 с.

## 4. Локальный ИИ без интернета

Файлы: `localLlm.ts`, `llm.worker.ts`, `LocalAiCard.tsx`, `facts.ts`.

- Модель **Qwen 2.5** (Apache 2.0) работает через **WebLLM** на видеокарте (WebGPU), в отдельном потоке.
- Две модели на выбор:
  - «Лёгкий» 0.5B: ≈300 МБ, по умолчанию на телефоне;
  - «Умный» 1.5B: ≈900 МБ, по умолчанию на ноутбуке.
- В ответчике есть карточка «ИИ без интернета». Через неё модель скачивается (с прогрессом), включается, удаляется. Там же галочка «Отвечать только локальным ИИ, даже когда есть интернет» — для демо без сети.
- **Защита от выдуманных фактов:**
  - к вопросу подкладывается проверенная справка (`facts.ts`: Абай, аль-Фараби, Арал, Байконур, фотосинтез, проценты, площадь, Пифагор, факт и мнение и др.) и ответы Википедии из кэша телефона;
  - низкая температура;
  - под ответом подпись «Может ошибаться — сверяйся с учебником».
- **Проверено в Edge:**
  - «Умная» скачалась за ≈90 с, потом запускается с диска за 3 с;
  - ответы верные: почему небо голубое, кто написал «Слова назидания» (Абай Кунанбаев), что такое фотосинтез;
  - скорость около 4–5 токенов/с на встроенной видеокарте Intel.
- «Лёгкая» модель без справки отвечала неверно, поэтому на ноутбуке по умолчанию стоит «Умная».
- Нужен WebGPU (Chrome/Edge на ноутбуке или новом Android). На старых телефонах карточка честно говорит, что не поддерживается.

## 5. Голос и казахское произношение

Файлы: `Speak.tsx`, `knowledge.ts` (`kkForRussianVoice`), `TalkingAvatar.tsx`, `api/tts.ts`.

- **Живой голос** через `/api/tts`, по одному предложению: первое звучит через 1–2 с, следующее грузится, пока играет текущее. Каждое предложение кэшируется на телефоне (`oqy-voice-v2`).
  - Сначала **ElevenLabs** `eleven_v3` (умеет казахский), mp3 22 кГц 32 кбит/с, ≈4 КБ на секунду речи. Включается переменной `ELEVENLABS_API_KEY`.
  - Иначе **Gemini TTS** (Kore — женский, Charon — мужской).
- **Голос телефона** (без сети, на 2G, без ключа):
  - выбирается по полу (Svetlana/Dariya — женские, Dmitry/Pavel — мужские);
  - казахский текст читает **казахский голос устройства** (Edge: Aigul, Daulet; Android: kk-KZ);
  - если казахского голоса нет, русский голос читает **казахскую транскрипцию**: ә→э, қ→к, ғ→г, ң→н, ұ→у, ү→ю/у, ө→ё/о, і→и, һ→х. Например, «Сәлем, қалайсың?» → «Сэлем, калайсын?»;
  - замена «буква на букву», поэтому синхронизация губ не сбивается.
- «Oqy» в речи всегда произносится как «Оқу».

**Не доделано:** на сайте с ключом Gemini казахские слова читает Gemini, а он не знает казахского и может говорить «салим». Есть два пути:
- (а) добавить `ELEVENLABS_API_KEY` в Vercel — лучший вариант;
- (б) в `api/tts.ts` перед отправкой в Gemini прогонять казахский текст через ту же транскрипцию. Пункт (б) ещё не сделан.

## 6. Мотивация: серия, XP, игры

Файлы: `streak.ts`, `SiteStreak.tsx`, `daily.ts`, `Badges.tsx`, `SiteBlitz.tsx`, `SiteQuiz.tsx`, `Shelf.tsx`, `SiteShell.tsx`, `SiteHome.tsx`.

- **Серия дней и заморозки:**
  - каждые 5 дней подряд дают заморозку;
  - пропущенный день сам тратит заморозку (окно с объяснением);
  - экран `/streak` показывает календарь недели.
- **XP и уровни:** 12 уровней, чип уровня в верхней полосе, цель дня. Задача дня даёт +20 XP один раз в день, таймер до новой задачи — в верхней полосе.
- **12 достижений** в «Мой кабинет».
- **Блиц-игра** `/blitz`:
  - 60 секунд «верно или неверно»: скидки, цена за кг, единицы, время в пути, факт или мнение (7 генераторов);
  - комбо ×2 и ×3, рекорд сохраняется, до 30 XP за игру;
  - после ответа показывается, какой вопрос объясняется.
- **Мини-тест PISA** `/quiz`.
- **Полка** на главной: подборка заданий и текстов.
- Тексты на «скучные» кнопки Duolingo **не** копировали. Взяли только механику серии и заморозок.

## 7. Демо для жюри и доказательство офлайна

- **`/jury` (и `/case`):**
  - один акцентный цвет, вверху 3 факта кейса (PISA, разрыв город–село);
  - пошаговый показ из 5 шагов, ссылки вида `?step=`: задача m-02 → ИИ-ответчик → блиц → офлайн → пример класса для учителя;
  - таблица требований кейса и как мы их закрываем;
  - блоки «Работает прямо сейчас» и «Включается ключом ИИ».
- **`/offline`, блок `OfflineProof.tsx`:** живые цифры с устройства — состояние сервис-воркера, сколько файлов и байт в кэше, сколько скачано за сессию, тип сети.
- **Проверено в Edge на 2G (250 кбит/с):** первый экран за ≈6 с, затем все файлы приложения сохраняются в телефоне. С полностью выключенной сетью открываются все экраны, задача решается, XP и серия считаются.
- Кнопка «★ Демо для жюри» в меню слева и плашка на главной.
- **Лендинг** `/home/`: ярче, новый раздел «Внутри приложения» со скриншотами, кнопки «Открыть приложение» и «Демо для жюри за 3 минуты».

## 8. Лёгкость и скорость

| Что | Размер | Когда качается |
|---|---|---|
| Приложение целиком (офлайн-набор, 66 файлов) | **1,17 МБ** | при первом открытии |
| 3D-модуль и модели аватаров | ≈1 МБ кода + 2,8 / 3,7 МБ моделей | при открытии ИИ-ответчика, кэш `oqy-3d` |

- Настроено в `app/vite.config.ts`: `globIgnores` и `runtimeCaching` с кэшами `oqy-3d` и `oqy-ai-engines`.
- ИИ и распознавание работают в Web Worker, интерфейс не подвисает.
- Громкость микрофона пишется прямо в CSS-переменную, без перерисовки экрана 20 раз в секунду.

## 9. Исправления перед жюри и что не закоммичено

**В `main` (коммит `33b763b`):**
- Без сети и без скачанного 3D экран ответчика раньше был белым. Теперь он отвечает голосом телефона и текстом.
- Распознавание речи и локальный ИИ без сети сообщают об ошибке, а не зависают на «Распознаю…».
- Страница учителя «Задать» и ещё 4 страницы вылезали за край экрана. Исправлено сеткой `minmax(0,1fr)`.

**Не закоммичено** (у капитана, `TalkingAvatar.tsx`, `talkinghead.d.ts`) — качество 3D-аватара:
- **Чёткость под устройство:** на ноутбуке холст рисуется с запасом по разрешению (≈1,9× на экране 125%), на бюджетном телефоне 1,25× и 24 кадра/с.
- **Замер плавности:** через 1,5 с после загрузки 4 секунды меряется частота кадров. Если ниже 35, разрешение снижается в 0,7 раза и частота до 20 кадров/с.
- **Пауза отрисовки,** когда аватар ушёл за экран или вкладка свёрнута (если он в этот момент не говорит).
- **Ресницы парня:** у модели AvatarSDK они без текстуры и рисовались светлыми пластинками вокруг глаз. Теперь они тёмные.
- **Края:** волос и ресниц сглажены (alpha-to-coverage), текстуры чётче под углом (анизотропия).
- **Свет:** теплее и ярче, добавлен контровой свет сзади для объёма.
- **У парня:** спокойное выражение (весёлое прищуривало глаза), меньше экспозиция (светлая кожа пересвечивалась), взгляд прямо.
- **Статус:** проверено на скриншотах (девушка стала глаже и ярче, артефакты у глаз парня пропали), последняя настройка света для парня ещё не перепроверена. Типы сходятся. Попадёт в `main` после коммита и пуша.

## 10. Аналитика (PostHog)

Файл `app/src/site/analytics.ts`. Ключ — публичный токен проекта в `VITE_POSTHOG_KEY`, сервер `VITE_POSTHOG_HOST=https://eu.i.posthog.com`. Без ключа ничего не отправляется.

События:
- `$pageview`, `task_answered`;
- `answerer_question`, `answerer_read_text`, `answerer_voice_gender`, `answerer_wiki`, `answerer_local_ai`;
- `local_ai_load`;
- `streak_event`, `daily_task_solved`, `quiz_finished`, `blitz_finished`.

В ИИ и аналитику не уходят имена, код класса и номер ученика. Дашборд в PostHog есть у капитана.

## 12. Как проверить (5 минут)

1. Открыть `/tutor`, разрешить микрофон, нажать зелёную кнопку и спросить «Как найти 15% от 24 000?». Текст должен появиться в поле, ответ прозвучит голосом.
2. Нажать «Мужской», дождаться приветствия. Написать «Сәлем! Қалайсың?» — ответ будет по-казахски.
3. Спросить «Кто такой Абай?» — ответ из Википедии с источником.
4. Открыть карточку «ИИ без интернета» → «Скачать» (на ноутбуке «Умный», ≈900 МБ) → отметить «только локальный ИИ» → спросить «Почему небо голубое?».
5. Открыть `/blitz` и сыграть 60 секунд.
6. Открыть `/jury` и пройти 5 шагов.
7. Обновить страницу, выключить сеть (режим самолёта), открыть главную, задание m-02, `/tutor`. Всё должно открываться и отвечать.

Автоматические проверки:
```bash
npm test && npx tsc --noEmit              # корень: 35 тестов сервера
cd app && npm test && npx tsc --noEmit -p . && npm run build   # 42 теста приложения, офлайн-набор 66 файлов ≈1,17 МБ
```
Тесты ответчика: `app/src/site/offlineAnswer.test.ts`, `knowledge.test.ts`, `server/tutor-voice.test.ts`.

**Что можно сделать следующим:**
1. Транскрипция казахского для Gemini в `api/tts.ts` (раздел 5, пункт б), если ElevenLabs не подключат.
2. Закоммитить качество 3D-аватара (раздел 9) после проверки на телефоне.
3. Ускорить Whisper на устройстве: WebGPU для кодировщика или модель tiny для слабых телефонов.

**Правила:**
- Работа в своей ветке, в `main` через PR, перед пушем проходят тесты и сборка.
- Без фиолетового цвета.
- Ключи только в Vercel.
- Тяжёлые модели не добавлять в офлайн-набор (`globIgnores` в `app/vite.config.ts`).
