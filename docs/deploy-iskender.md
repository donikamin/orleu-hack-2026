# Деплой на Vercel через свой аккаунт (для Искендера)

Сайт разворачивается из **твоего** аккаунта Vercel через командную строку. Аккаунт капитана и его настройки не нужны.
Этот файл можно целиком отдать своему Claude Code: «Сделай деплой по docs/deploy-iskender.md».

## Как это устроено

- Код — в репозитории капитана `donikamin/orleu-hack-2026`, ветка `main`. У тебя есть доступ на запись.
- Сайт — в твоём Vercel. Автообновления по пушу нет: после изменений в `main` сайт обновляется одной командой (шаг 6).
- Ключи (Anthropic, Supabase, бот) живут только в твоём Vercel. В репозиторий и в чат их не вставлять.

## Инструкция для Claude Code

Выполняй по порядку в корне репозитория. Ключи сам не вводи и не проси прислать в чат — их вписывает человек в панели Vercel (шаг 4).

1. **Обновить код.** `git switch main && git pull origin main`. Убедиться, что рабочая копия чистая.
2. **Проверить сборку локально.** `npm ci && npm ci --prefix app && npm test && npm run build --prefix app`. Если что-то упало — остановиться и показать ошибку.
3. **Войти и привязать проект.** `npx vercel login` (откроется браузер: человек входит через GitHub), затем `npx vercel link --yes`. Настройки сборки уже в `vercel.json`, менять их в панели не нужно.
4. **Ключи — делает человек.** Попросить открыть vercel.com → проект → Settings → Environment Variables и добавить для Production имена из `.env.example`:
   `ANTHROPIC_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `CRON_SECRET` (два последних — любые случайные строки от 20 символов; их можно сгенерировать командой `node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"`).
   Необязательно: `AI_MODEL=claude-haiku-5-5` — подсказки и проверка в ~40 раз дешевле.
   Дождаться, пока человек напишет «готово». Проверить список: `npx vercel env ls` (значения он не покажет).
5. **Выкатить.** `npx vercel --prod`. В конце будет ссылка `https://….vercel.app` — показать её человеку.
6. **Обновлять сайт после изменений в main:** `git pull origin main && npx vercel --prod`.
7. **Бот, один раз после первого деплоя:** `npm run bot:setup -- https://АДРЕС.vercel.app`.

## Проверка после деплоя

- `https://АДРЕС.vercel.app/` — открывается лендинг с боковой панелью.
- `https://АДРЕС.vercel.app/demo` — открывается демо-класс с гидом.
- `https://АДРЕС.vercel.app/api/pack?v=1` — отдаёт JSON с 54 заданиями.
- В демо-классе: «Урок на доске», подсказка по клавише П.
- Если что-то не так: `npx vercel logs https://АДРЕС.vercel.app` и прислать ошибку в общий чат.

## Частые проблемы

| Что видно | Что делать |
|---|---|
| `Error: No framework detected` | Нормально, настройки берутся из `vercel.json`. Проверить, что команда запущена в корне репозитория |
| `/api/...` отвечает 503 | Не вписаны ключи Supabase или не сделан повторный `npx vercel --prod` после их добавления |
| Подсказки статические, без ИИ | Нет `ANTHROPIC_API_KEY` или на счёте Anthropic нет денег |
| Функция падает по времени на фото | Тариф Hobby ограничивает 60 с; фото обычно укладывается в 30 с. Повторить с фото поменьше |

Ссылку на сайт — в общий чат, капитан вставит её в форму сдачи.
