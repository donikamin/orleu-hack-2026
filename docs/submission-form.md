# Форма сдачи hackathon.kz — что вставить в каждое поле

## Название проекта
Oqy — ИИ-тренажёр чтения и математики, который работает без интернета

## Описание
Oqy (каз. «оқы» — «читай») — тренажёр функциональной грамотности для 7–9 классов, кейс 3 «Читать и понимать». Сделан для сельских школ, где интернет слабый или его нет.

Что уже работает:
• 3D-ИИ-ответчик: спрашиваешь голосом — он отвечает вслух, двигает губами, показывает субтитры. Понимает казахский и отвечает по-казахски (живой голос ElevenLabs), знает «обо всём» через Википедию, читает тексты вслух. Задачу за ученика не решает — ведёт подсказками.
• ИИ без интернета: модель Qwen 2.5 скачивается один раз по Wi-Fi и дальше отвечает прямо на устройстве, без сети и без лимитов. Речь тоже распознаётся на устройстве (Whisper).
• 89 заданий из жизни: 51 по чтению в формате PISA (найти, понять, оценить), 30 по математике (деньги, проценты, скорость и нормы, измерения, графики), 8 новых форматов. 5 текстов с голосом, 6 уроков по 5 минут.
• Блиц-игра «верно или неверно» на 60 секунд (26 вопросов за минуту), мини-тест PISA за 10 минут с уровнем по каждому навыку.
• Серия дней, заморозки, XP, 12 уровней, задача дня, достижения.
• Всё приложение — 1,2 МБ в телефоне: работает в режиме самолёта, первый экран на 2G за ~6 с. Результаты учителю — QR-кодом без интернета.

Как проверить: откройте ссылку «Демо для жюри» — 5 шагов по всем функциям за 3 минуты. Затем включите режим самолёта и обновите страницу — приложение продолжит работать.

Стек: React PWA, Service Worker, IndexedDB, TalkingHead (3D), WebLLM + Qwen 2.5, Whisper, Vercel, Gemini/Claude, ElevenLabs. Разработка с Claude Code.
